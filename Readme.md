# Rematch

Rematch is a 3D third-person action strategy game built in Godot 4.6.

## Features

- Third-person character movement and camera control
- Run, jump, and smooth directional movement
- A special chessboard-style skill effect
- A test world for exploring the current gameplay setup
- Main menu and intro scenes for starting the project

## How to Open in Godot 4.6

1. Install Godot 4.6.
2. Open the project by selecting the project file at [project.godot](project.godot).
3. Wait for Godot to load the project.
4. Open the main test scene at [scenes/Maps/Test_world.tscn](scenes/Maps/Test_world.tscn) if you want to play the current build.
5. Press Play in the Godot editor to run the project.

## Controls

- WASD: Move
- Mouse: Look around
- Shift: Run
- Space: Jump
- Q: Use the chessboard skill when available
- Esc: Toggle mouse capture
